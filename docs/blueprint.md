# **App Name**: MicroLearnAI

## Core Features:

- Topic Display: Display the selected topic, such as 'Arrays'.
- AI Micro Lesson Generation: Generate concise, bite-sized lesson content based on the displayed topic using AI.
- Lesson Content Display: Display the AI-generated lesson content in a card layout.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of trust and focus.
- Background color: Very light blue (#E8EAF6), a desaturated shade of the primary color, to provide a clean backdrop.
- Accent color: Purple (#7E57C2), an analogous hue to the primary color, to draw attention to interactive elements.
- Body and headline font: 'Inter' for a modern and neutral aesthetic, suitable for both headings and lesson content.
- Use simple, outline-style icons to represent different aspects of the lessons.
- Clean, minimal layout with ample white space to focus attention on the content.
- Subtle fade-in animations when new lesson content is generated and displayed.
